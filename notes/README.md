# Project notes

Use this folder for interview notes, usability observations, hypotheses, experiments and implementation notes. Date each note. Separate observations from interpretation and decisions.

Do not place raw Strava exports, names, emails, route coordinates, activity IDs or other identifiable data here. Use `fixtures/` for approved synthetic or de-identified examples.

Suggested note structure:

```md
# YYYY-MM-DD — Topic

## Context
## Observations
## Interpretation / hypotheses
## Follow-up questions
## Decisions to record
```
