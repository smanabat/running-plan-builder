# Security policy

This repository is an early prototype. Do not use it with production credentials or real user data.

Please do not open a public issue containing account details, activity exports, route information, credentials or suspected vulnerabilities. If private vulnerability reporting is enabled for the repository, use it. Otherwise contact the repository owner privately without including sensitive data in a public issue.

Before accepting real users, review authentication, access rules, upload retention, App Check, abuse controls, logging, backups and incident response.
